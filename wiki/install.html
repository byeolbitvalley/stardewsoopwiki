홈설치 · 접속게임 안내후원 보상자주 묻는 질문

설치 · 접속

한 번만 설치하면 됩니다. 설치기가 SMAPI(모드 실행기)와 별빛골짜기 모드를 함께 설치합니다.

준비물

  • Windows PC, Steam판 스타듀밸리
  • 인터넷 (SMAPI를 공식 사이트에서 받습니다, 약 40MB)
  • Microsoft Edge (Windows에 기본 설치되어 있음, /숲로그인에 사용)
  • 운영자에게 받은 설치기 파일 SOOP스타듀_설치기.zip

설치

  1. 스타듀밸리를 끕니다.
  2. SOOP스타듀_설치기.zip을 오른쪽 클릭 → 압축 풀기 합니다. zip 안에서 바로 실행하면 안 됩니다.
  3. 풀린 폴더의 설치.bat을 더블클릭합니다.
    • 스타듀밸리 폴더를 자동으로 찾습니다. 못 찾으면 폴더 주소를 물어봅니다 (Steam → 스타듀밸리 오른쪽 클릭 → 관리 → 로컬 파일 보기).
    • SMAPI가 없거나 오래됐으면 SMAPI 4.5.2를 설치합니다.
    • 트랙터 이용권에 쓰는 Tractor Mod(Pathoschild)도 함께 설치합니다. 이미 같은 버전 이상이 있으면 그대로 둡니다.
    • 별빛골짜기 서버에서는 다른 모드를 쓸 수 없습니다. 설치기가 다른 모드를 찾으면 지우지 않고 Mods_bak 폴더(이미 있으면 Mods_bak_날짜)로 옮깁니다. 별빛골짜기 모드의 설정과 SOOP 연결 정보, Tractor Mod 설정은 그대로 남습니다.
    • 바탕화면에 스타듀밸리 (SOOP 모드) 바로가기를 만듭니다.
    • Steam의 실행 옵션에 SMAPI를 자동으로 넣습니다. Steam이 켜져 있으면 넣는 동안 Steam을 잠깐 껐다 켤지 묻습니다 (Steam이 켜져 있는 동안에는 설정을 바꿀 수 없어서입니다). N을 눌러도 바탕화면 바로가기로 실행할 수 있습니다. 이미 설정되어 있으면 묻지 않고 넘어갑니다.
처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

게임 실행

  • 바탕화면 바로가기 "스타듀밸리 (SOOP 모드)"로 실행합니다. Steam이 켜져 있어야 합니다.
  • 설치기가 실행 옵션을 넣었다면 Steam의 플레이 버튼으로 켜도 모드와 함께 켜집니다.
  • 실행 옵션을 넣지 않았다면(N을 누른 경우): 스타듀밸리 오른쪽 클릭 → 속성 → 일반 → 시작 옵션에 설치 창이 알려 준 문구를 붙여 넣습니다. 설치기가 클립보드에 복사해 둡니다.
시작 옵션 없이 Steam에서 그냥 실행하면 모드 없이 켜집니다. 게임과 함께 뜨는 검은 창에 SOOP Stardew Bridge가 보이면 정상입니다.

서버 접속

  1. 타이틀 화면에서 협동 → 참가를 누릅니다.
  2. 초대코드 입력을 누르고 운영자에게 받은 초대코드를 넣습니다.
  3. 처음이면 빈 칸을 골라 캐릭터를 만듭니다. 새 캐릭터로 처음 접속하면 시작 선물로 녹슨 검이(가) 인벤토리에 들어옵니다. Steam 계정 하나에 캐릭터 하나만 만들 수 있습니다.

업데이트

새 설치기를 받아 설치.bat을 다시 실행하면 됩니다. 기존 모드 폴더를 지울 필요 없이 그 위에 덮어씁니다. 설정과 SOOP 연결 정보는 그대로 남습니다.

설치기는 운영자에게 직접 받은 것만 쓰세요. SOOP 로그인은 SOOP 공식 로그인 화면에서만 하며, 별빛골짜기 서버와 모드는 SOOP 비밀번호를 볼 수 없습니다. 연동에 쓰는 권한은 채팅 정보 읽기뿐입니다.
